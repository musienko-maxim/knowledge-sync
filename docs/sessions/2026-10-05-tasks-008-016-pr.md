## PR title

Add OAuth account synchronization and deterministic Obsidian export

## PR description

Saved videos can now be synchronized from all owned YouTube playlists into local
SQLite and optionally exported to an existing Obsidian vault. Shared videos stay
one item and one note while retaining every observed playlist membership.

- Add deterministic Markdown rendering, stable identity-based note paths, and
  single/batch filesystem export. Connect single-playlist synchronization to a
  full persisted-snapshot export through `youtube sync-obsidian`.
- Persist collections and many-to-many memberships with composite identities
  and enforced foreign keys. Add tables without changing existing item/import
  records; historical playlist titles are not used to invent membership IDs.
- Add OAuth-only `youtube sync-all`, with `--db` and optional explicit `--vault`.
  Reuse existing discovery and collection logic, synchronize sequentially, then
  optionally export the full database snapshot once. Environment vault settings
  alone never enable account export.
- Continue after recoverable playlist failures, retaining partial writes.
  Authentication, exhausted quota, and specified SQLite infrastructure errors
  stop further work and suppress export. Keep prior outcomes and unattempted
  counts; report playlist and export failures together with safe diagnostics.
- Preserve existing commands and legacy collection-title Markdown behavior.
  Item counters sum processing events from completed playlists only; partial
  writes from failed playlists are intentionally excluded.
